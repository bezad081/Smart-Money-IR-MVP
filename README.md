# Smart Money IR — MVP

نسخه شخصی و محلی برای تحلیل رفتار حقیقی و حقوقی بورس ایران. مسیر اصلی توسعه این نسخه فقط Python است؛ React، TypeScript، Node.js، Docker و PostgreSQL برای اجرای آن لازم نیستند.

## امکانات نسخه اولیه

- داشبورد فارسی و راست‌چین با Streamlit
- نمودارهای تعاملی قیمت و جریان خرید/فروش حقوقی با Plotly
- جست‌وجو و افزودن نماد از TSETMC
- ذخیره تاریخچه یک‌ساله قیمت و حقیقی/حقوقی در یک فایل Excel
- نمایش خرید، فروش، خالص خرید و سهم حقوقی از خرید و فروش
- اسکنر رتبه‌بندی نمادها بر اساس خالص خرید یا فروش حقوقی
- تشخیص قواعد اولیه انباشت و توزیع حقوقی
- آزمون تاریخی بازده ۱، ۳، ۴، ۵ و ۱۰ جلسه بعد از الگو
- همگام‌سازی دستی و زمان‌بندی خودکار روزانه
- پشتیبان‌گیری و بازیابی فایل Excel

## اجرای سریع در Windows

1. Python 3.10 یا جدیدتر را نصب کن.
2. مخزن را روی لپ‌تاپ Clone یا Download کن.
3. فایل `run_windows.bat` را اجرا کن.

یا دستورات را دستی در ترمینال اجرا کن:

```powershell
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py
```

برنامه به‌صورت محلی در مرورگر باز می‌شود: http://127.0.0.1:8501

## اجرا در macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m streamlit run app.py
```

یا: `bash run_mac_linux.sh`

## فایل داده

در اولین اجرا فایل زیر ساخته می‌شود:

`data/SmartMoneyData.xlsx`

Sheetهای اصلی:
- `Symbols`: نمادهای تحت پیگیری
- `Portfolio`: تعداد و میانگین قیمت خرید
- `DailyData`: قیمت و آمار حقیقی/حقوقی روزانه
- `Signals`: رخدادهای تاریخی الگو
- `SyncLog`: گزارش دریافت داده

فایل Excel را هنگام همگام‌سازی در Microsoft Excel باز نگذار. برنامه قبل از نوشتن، فایل را به‌صورت موقت می‌سازد و سپس جایگزین می‌کند. فایل‌های داده محلی در Git ثبت نمی‌شوند؛ برای پشتیبان‌گیری از دکمه دانلود Excel داخل برنامه استفاده کن.

## همگام‌سازی خودکار

پس از اجرای برنامه، زمان‌بند محلی فعال می‌شود و به‌طور پیش‌فرض شنبه تا پنجشنبه ساعت ۱۸:۳۰ به وقت تهران همگام‌سازی می‌کند. ساعت قابل تغییر است. برای اجرای خودکار، فرایند Streamlit باید روی لپ‌تاپ در حال اجرا باشد؛ در صورت خاموش بودن لپ‌تاپ یا بسته شدن فرایند، اجرای زمان‌بندی‌شده انجام نمی‌شود. همگام‌سازی دستی همیشه از داخل برنامه قابل اجراست.

## منبع داده و محدودیت دسترسی

آداپتر اولیه از مسیرهای شناخته‌شده CDN مربوط به TSETMC استفاده می‌کند:
- `/Instrument/GetInstrumentSearch/{query}`
- `/ClosingPrice/GetClosingPriceDailyList/{insCode}/0`
- `/ClientType/GetClientTypeHistory/{insCode}`

این مسیرها API رسمیِ تضمین‌شده با قرارداد پایداری نیستند؛ ممکن است تغییر کنند، فیلدها عوض شوند یا بعضی IPها مسدود شوند. دسترسی TSETMC از شبکه‌های خارج ایران نیز ممکن است محدود باشد. اولین تست را با یک یا دو نماد انجام بده و صحت ستون‌ها را با صفحه نماد در TSETMC مقایسه کن.

تاریخ‌های `dEven` و `recDate` در این مسیرها به قالب میلادی `YYYYMMDD` هستند. برای روزهایی که رکورد حقیقی/حقوقی از منبع پیدا نشود، ستون `ClientDataAvailable` مقدار False می‌گیرد و آن روز در تشخیص الگو لحاظ نمی‌شود.

منابع فنی برای بررسی ساختار API:
- https://github.com/amirziveh/tsetmc-skill
- https://github.com/5j9/tsetmc
- https://github.com/BabakEslami/tse-market-data

## تعریف شاخص‌ها

- خالص خرید حقوقی = حجم خرید حقوقی − حجم فروش حقوقی
- درصد خالص خرید از حجم روز = خالص خرید حقوقی ÷ حجم کل معاملات × ۱۰۰
- سهم خرید حقوقی از کل خرید = خرید حقوقی ÷ (خرید حقوقی + خرید حقیقی) × ۱۰۰
- سهم فروش حقوقی از کل فروش = فروش حقوقی ÷ (فروش حقوقی + فروش حقیقی) × ۱۰۰

این نسبت‌ها مفهوم یکسانی ندارند و جداگانه نمایش داده می‌شوند.

## روش تحلیل و هشدار

در نسخه اولیه:
- انباشت: خالص خرید حقوقی در سه جلسه پیوسته مثبت، نسبت خالص خرید به حجم حداقل ۲٪ در هر روز و قیمت کم‌تحرک.
- توزیع: خالص فروش حقوقی در سه جلسه پیوسته، نسبت خالص فروش به حجم حداقل ۲٪ در هر روز و قیمت نزدیک سقف ۶۰ جلسه اخیر.

امتیاز نمایش داده‌شده قدرت قواعد است، نه احتمال آماری. نتایج تاریخی تضمین‌کننده آینده نیستند. آزمون فعلی مقدماتی است و قیمت تعدیل‌نشده، توقف نماد، افزایش سرمایه، کارمزد، دامنه نوسان و سوگیری بقا می‌توانند نتیجه را تغییر دهند. داده تجمیعی حقیقی/حقوقی، هویت خریدار یا فروشنده حقوقی منفرد را مشخص نمی‌کند.

## حریم خصوصی

برنامه با آدرس `127.0.0.1` اجرا می‌شود و برای استفاده عادی نیاز به انتشار اینترنتی ندارد. فایل Excel محلی است و وارد Git نمی‌شود. اطلاعات صرفاً در صورت فعال بودن اتصال اینترنت برای دریافت داده به TSETMC ارسال/دریافت می‌شود.
